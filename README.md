# Sale-Data-Analysis
Sales Data Analysis with Python

Overview: This project focuses on analyzing sales data using Python. The objective is to explore and extract insights from a dataset that contains sales information for various products. The analysis includes calculating total sales, identifying trends over time, and understanding the relationship between product price and total sales.

Key Tools and Libraries Used:
1. pandas: For data manipulation and analysis.
2. matplotlib: For creating basic plots and visualizations.
3. seaborn: For enhanced data visualizations.

Steps in the Project:

1. Data Loading and Inspection:
-The CSV file containing the sales data is loaded into a pandas DataFrame.
-The first few rows are displayed for inspection.

2. Data Cleaning:
-Data is cleaned by adding a new column, Total, which represents the total sales amount per transaction (Quantity * Price).

3. Data Analysis:
-Calculated total sales per product.
-Analyzed total sales over time (daily sales trend).

4.Data Visualization:
-Created bar plots to visualize total sales per product.
-Created a line plot to show sales trends over time.
-Created a scatter plot to explore the relationship between product price and total sales.

5. Insights and Conclusion:
-Identified the best-selling products.
-Identified sales trends over time.
-Analyzed the correlation between price and total sales.

6. Saving Results:
-The analysis results are saved into a new CSV file, sales_analysis_result.csv.
